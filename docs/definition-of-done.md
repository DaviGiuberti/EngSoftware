# Definition of Done

Uma história só está PRONTA quando:

1. O código está numa branch curta e foi integrado na main por PR.
2. Tem testes automáticos, e as regras de negócio têm teste unitário.
3. Passou pelo auto-review e pelo review da IA.
4. A CI passou (lint, typecheck, testes, cobertura, scan de dependências).
5. A documentação foi atualizada quando necessário.
6. (Nova DoD, a partir da Nota 04) Tem log, métrica ou alerta, e um jeito de voltar atrás (rollback).
